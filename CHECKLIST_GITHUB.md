# Checklist do repositório

- [x] Repositório criado e nome corrigido.
- [x] Visibilidade privada confirmada.
- [x] Branch principal main confirmada.
- [x] Documentos centrais enviados.
- [ ] Revisar conteúdo diretamente no GitHub.
- [ ] Configurar proteção de main e revisão de alterações.
- [ ] Ativar autenticação forte e revisar tokens/permissões.
- [ ] Validar a estrutura em ambiente limpo.
- [ ] Testar instalação manual em outra conta/dispositivo do titular.
- [ ] Criar tag de release após testes reais.

## Limites
O envio dos documentos não implementa runtime, agentes executáveis ou integrações. Esses itens permanecem no roadmap.
