# GAME DEV AUTONOMOUS AI ULTIMATE

Skill modular para planejar, coordenar e executar desenvolvimento de jogos com agentes de IA, ferramentas 3D e motores de jogo.

## Estado
**Versão documental:** 1.0.0  
**Implementação:** especificação inicial; runtime, adaptadores e integrações ainda precisam ser construídos e validados.

## Objetivo
Coordenar fluxos de game development para Roblox Studio e Unity, com apoio de Blender, Tripo3D, ComfyUI, Ollama, Codex, Claude Code, GitHub e serviços compatíveis via API/MCP/CLI/GUI.

## Princípios
- Preservar projetos originais; trabalhar em cópias e branches de desenvolvimento.
- Separar planejamento, execução segura e operações que exigem aprovação.
- Não presumir que ferramentas estão conectadas: verificar cada integração.
- Registrar decisões, alterações, testes, custos e proveniência dos assets.
- Autonomia limitada por permissões explícitas e pelo escopo do projeto.

## Estrutura
- `SKILL.md`: instruções centrais para o agente.
- `AGENTS.md`: papéis e responsabilidades dos agentes.
- `docs/`: arquitetura, segurança, workflows, APIs e padrões.
- `config/`: manifesto e changelog.

## Início
Leia primeiro `SKILL.md`, depois `AGENTS.md`, `docs/SECURITY.md` e `docs/IMPLEMENTATION_PLAN.md`. Comece em modo READ_ONLY; avance para planejamento e execução apenas com autorização apropriada.

## Compatibilidade
Este repositório é uma especificação portátil. Os formatos nativos e caminhos de instalação de Codex, Claude Code e outras plataformas devem ser validados na versão efetivamente utilizada. Não instala nada automaticamente.

## Distribuição
Repositório privado destinado ao titular. A instalação em outras contas ou computadores do próprio titular é manual e depende das permissões e dos termos de cada ferramenta. Não tornar público nem redistribuir a terceiros sem autorização do titular.
