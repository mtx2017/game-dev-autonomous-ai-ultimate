# Pipeline de assets

## Categorias
Personagens, monstros, chefes, armas, armaduras, props, mapas, animações, rigging, VFX, materiais, texturas e áudio.

## Etapas
Brief → referências com licença → conceito → blockout → produção → retopologia/UV → materiais → rig/animação → otimização → importação em projeto de desenvolvimento → QA.

## Ferramentas
Blender para criação/ajustes; Tripo3D ou serviços similares quando autorizados; ComfyUI para imagens/workflows; Roblox Studio e Unity para integração.

## Formatos
Definir por motor e versão. FBX, GLB/glTF, PNG, WAV e formatos nativos são candidatos, não garantias universais. Validar escala, eixos, unidades, rig, materiais e limites.

## Performance
Polígonos, draw calls, materiais, textura/VRAM, bones, partículas e LOD devem ter budgets por plataforma.

## Licenças
Registrar origem, autor, licença, restrições comerciais e permissões de uso. Não copiar assets sem direito de uso.
