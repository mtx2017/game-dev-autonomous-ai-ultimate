# Interface proposta

## Áreas
- **Agents Center:** agentes, tarefas, estado e logs.
- **Game Studio:** projetos, cenas, sistemas e milestones.
- **3D Studio:** modelos, rigs, animações e assets.
- **AI Center:** modelos locais/remotos, endpoints e limites.
- **Workflow Center:** fluxos, dependências e aprovações.
- **GitHub Center:** branches, commits, PRs e releases.
- **QA Lab:** casos, resultados, evidências e regressões.
- **Security Center:** permissões, zonas, auditoria e emergency stop.
- **Settings:** integrações, idioma, limites e preferências.

## Requisitos
Português-BR como idioma inicial, interface responsiva, acessibilidade, confirmação para ações de risco, histórico pesquisável e indicação clara de modo operacional.

## Arquitetura sugerida
Frontend independente do backend; API autenticada; eventos em tempo real; autorização no servidor. Não confiar apenas em ocultar botões na interface.
