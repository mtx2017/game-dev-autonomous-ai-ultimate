# Plano de implementação

## Fase 0 — Preparação
Validar plataformas, requisitos, formatos de skill, política de permissões e estrutura de workspace. Nenhuma instalação sem autorização.

## Fase 1 — Core
Implementar contratos, configuração, logger, permission manager, task state machine e emergency stop.

## Fase 2 — Agentes
Adicionar agentes por especialidade, roteamento, limites, revisão e prevenção de conflitos.

## Fase 3 — Codex + Claude Code
Validar suporte nativo atual; criar adaptadores separados; implementar handoff explícito e contexto mínimo compartilhado.

## Fase 4 — Integrações
Conectar GitHub, Blender, Roblox Studio, Unity, ComfyUI, Ollama e serviços autorizados. Cada integração passa por health check e teste isolado.

## Fase 5 — Produção
Implementar workflows de assets, gameplay, mundo e multiplayer em cópias de projeto.

## Fase 6 — QA
Automatizar testes unitários, integração, regressão, segurança e desempenho; exigir evidências.

## Fase 7 — Cloud
Adicionar execução remota somente com isolamento, controle de custos, gestão de segredos e política de dados.

## Fase 8 — Validação final
Auditoria independente, recuperação de backup, teste de permissões, documentação, versionamento e release.

## Critérios de avanço
Cada fase precisa de entregáveis verificáveis, testes PASS, riscos aceitos e aprovação do titular quando houver operações críticas.
